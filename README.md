# JR Dakconstruct, demo
Een onafhankelijk websitevoorstel van Bloxflow. Statische HTML/CSS/JavaScript; geen installatie of build nodig.

Lokaal: `python3 -m http.server 5192 --directory dist`

Open http://localhost:5192. Het formulier valideert uitsluitend lokaal; er wordt niets verstuurd of opgeslagen. Beelden en contactgegevens komen van de bestaande website van JR Dakconstruct; zie asset-sources.json en PRODUCT.md. De calculator gebruikt voorbeeldtarieven.
